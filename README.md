# Store Products Dashboard

## Description
This project is a simple product dashboard built with HTML, CSS, and JavaScript. It uses the Store Products API to fetch product data and display product cards on the page. Each product card includes the product name, image, and price. The dashboard also includes hover effects to make the user interface more interactive.

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API
- Async/Await
- Try/Catch Error Handling
- DOM Manipulation

## Features
- Fetches product data from an external API
- Logs product names to the console using `.then()`
- Uses `async/await` to retrieve and display products
- Displays the first five products as product cards
- Shows product name, image, and price
- Includes reusable error handling
- Adds hover effects with CSS transitions

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Make sure the following files are included:
   - `index.html`
   - `style.css`
   - `cp_2.js`
4. Open `index.html` in a web browser.
5. Open the browser console to see the product names logged from the API.

I practiced using both `.then()` and `async/await` for asynchronous operations.
